# 03 - Findings Triage Workflows

This section covers triaging, prioritizing, and managing findings efficiently through automated workflows and manual processes.

## Available Scripts

- **[autotriage](./autotriage/)** - Automates finding triage based on configurable rules including risk scoring, categorization, priority assignment, duplicate detection, and false positive marking
- **[clone-version-to-project](./clone-version-to-project/)** - Branches a project version into a new project, carrying over component statuses, exclusions, edits, finding VEX and comments
